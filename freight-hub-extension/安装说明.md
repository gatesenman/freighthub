# 货代询价助手 FreightHub · Chrome 扩展 v1.0.1（未授权版本 / 试用）

在浏览器右侧的「侧边栏」里一键查询多个货代平台的运价：显示**每个平台的最低价**和**全部最低价**，可看全部渠道明细和历史。只读查询，不下单、不改平台密码。

> 当前是**试用版**：侧边栏和设置页带「未授权版本 / 试用」水印和角标，不能关闭，仅供演示 / 评估。

## 一、安装（开发者模式加载，1 分钟）
要求：Chrome 116 或更新版本（基于 Chromium 的 Edge 同理，但本版本只在 Chromium 上测过）。

1. 把 `FreightHub-Chrome-1.0.1.zip` **解压**到一个固定的文件夹（装好后不要删除或移动这个文件夹）。解压后文件夹里应能直接看到 `manifest.json`。
2. 地址栏输入 `chrome://extensions` 回车。
3. 打开右上角 **「开发者模式」**。
4. 点 **「加载已解压的扩展程序」**，选择第 1 步里含 `manifest.json` 的那个文件夹。
5. 列表里出现「货代询价助手 FreightHub（试用）」即安装成功；点浏览器工具栏的拼图图标，把它 **固定（图钉）** 到工具栏。
6. 提示「停用开发者模式扩展程序」的弹窗，选「保留」即可（这是 Chrome 对未上架扩展的固定提示）。

## 二、使用
- **打开侧边栏**：点工具栏图标，或按快捷键 **Alt+Shift+F**（可到 `chrome://extensions/shortcuts` 修改）。
- **快速查询**：顶部输入框写「美国 2kg 30x20x10」或「US 1kg」回车。也可以分别填 目的国 / 重量 / 尺寸，点「查询」。
- **各平台最低价**：每个平台一行，显示该平台最便宜的渠道、价格、时效；全部最低的那一行标「全场最低」。点某个平台行，会跳到「全部结果」并只看该平台。
- **全部结果**：表格，可按平台 / 渠道 / 总价 / 时效排序，可筛选，点一行展开费用明细。
- **历史**：最近的查询，点一条重新载入结果。
- **网页里选中文字查询**：在任何网页里选中「US 1kg」这样的文字 → 右键 → **用 FreightHub 询价**，侧边栏会自动打开并查询。

## 三、选择查询后端（工具栏图标 → 侧边栏右上角 ⚙，或 `chrome://extensions` → 详细信息 → 扩展程序选项）
| 后端 | 说明 |
|---|---|
| **网页版**（默认） | `https://freight.gaosichun.dev`，需要登录。在侧边栏登录表单里输入账号即可；勾选「保持登录」只保存站点会话（30 天），**扩展不保存密码**。 |
| **本机桌面版** | `http://127.0.0.1:8765`，需要先启动 FreightHub 桌面软件。无需登录。 |

换成自定义网址时，保存后浏览器会弹窗请求访问该站点的权限，点「允许」。设置页的「检测连接」可以检查连通和登录状态。

## 四、常见问题
- **提示「连不上网页版 / 本机桌面版」**：检查网络；桌面版请先启动软件；或在设置页切换后端。
- **提示「网页版拒绝了扩展的来源（Origin）」**：正常情况下不会出现（扩展已内置兼容）。若出现，请让网页版管理员在服务端环境变量 `FREIGHT_HUB_ALLOWED_ORIGINS` 里加入本扩展 ID：`jepddgoigapaeamalcmjembhbpllalog`。
- **某个平台显示失败 / 超时**：不影响其他平台；鼠标悬停可看完整原因。网页版部署在海外时，部分平台可能无法访问，请改用桌面版。
- **没有「运行查询」权限**：用的账号角色没有查询权限，联系管理员。
- **卸载**：`chrome://extensions` → 移除。会清除设置，不会影响网页版 / 桌面版数据。

## 五、隐私与安全
- 扩展不保存账号密码、不读取 Cookie 内容；只存：后端设置、上次输入的文字。
- 只访问你在设置里选的后端（默认网页版地址和本机 127.0.0.1），不上传到任何第三方。
- 只读：不会下单、不重置平台密钥、不修改平台密码。
