四、发现并修复的问题

#严重度问题原因处理
1中OIS 接口地址填空格时被拼成 https://ois_base 对空白串没有回退到默认地址已修复：strip 后为空则用默认值
2低到货天数写成小数（如 0.5-1）被错误拆分parse_days 只匹配整数已修复：支持小数并向上取整
3中金额 NaN / Infinity 被当作有效数字to_float 未过滤非有限值，序列化 /api/quote 会 500已修复：非有限值一律视为无效
4中上游返回 0 价 / 负价 / 非数字价的行混进结果多个适配器各自过滤，口径不一已修复：Adapter.quote 统一 clean_rows
5中/api/quote 入参缺校验NaN、超大重量、负尺寸、超长国家/邮编都能进入适配器；422 回显原始输入时遇 NaN 变 500已修复：Field 范围限制 + 422 不回显原值
6高网络错误信息可能带出 URL 查询串里的密钥顺丰国际取 token 用 GET 参数传 appKey/appSecret，requests 异常文本含完整 URL已修复：新增 redact()，错误信息统一脱敏
7中config.json 先以 644 创建再 chmod 600写入与改权限之间存在可读窗口已修复：os.open(..., 0o600) 创建即私有
8高配置文件损坏后下一次保存会覆盖用户凭据读取失败静默返回空配置已修复：先备份为 config.json.corrupt-xxxx（0600）
9中导出 CSV / 前端复制含公式注入以 = + - @ 开头的渠道名会被 Excel 当公式执行已修复：服务端与前端 csvCell 均加前缀单引号
10高无登录失败锁：凭据错误时每次查询都会重试登录可能触发平台风控锁号，违反「登录只试一次」已修复：登录/鉴权失败后持久化锁定，改凭据或点「测试连接」才解锁
11中导入：zip 炸弹 / 异常列号 / 过大文件xlsx 解压无上限，ZZZZZZ1 之类列号让补齐列表膨胀已修复：解压 80MB、列号 500、1000 行、10MB 上限
12低未实现登录模式的平台默认显示「登录」雨桐/顺丰/燕文只能走 API，默认却是登录模式已修复：default_mode=api，并加短文案列
13中顺丰沙箱用正式密钥报 1005 App is not exist，提示不清沙箱是独立环境，需沙箱专用密钥已修复：沙箱 1005 给出明确指引（见第六节）
14中旧测试结果 JSON 里含真实客户标识tests/last_result.json、api_mode_result.json 记录了授权成功消息里的客户名；v1.3.0 安装包随带 tests/已修复：JSON 已脱敏；1.4.0 安装包不再包含 tests 目录。v1.3.0 安装包按要求原样保留，未改动

另有两项界面修复（用户提出）：平台账号页「对接方式」列改为简称（完整说明放在悬停提示与平台说明中）；「操作日志」面板撑满剩余高度并随窗口缩放（flex:1，无下方空白）。均有 Playwright 用例，截图见第七节。

六、顺丰国际 沙箱试算

已支持 env=sandbox（沙箱地址 https://api-ifsp-sit.sf.global；用 http:// 访问会返回 500，需用 https）与 customerCode 配置项（仅存 data/config.json）。按要求只做了一次只读尝试：沙箱取 token 返回 1005 App is not exist，因此没有继续发起 IUOP_QUERY_FREIGHT 试算，也没有重试。原因：沙箱是独立环境，控制台里的生产 Key / 密钥 / AES 密钥在沙箱不存在；需使用控制台「前往沙盒」里的沙箱专用 APP Key、密钥、AES 秘钥。另外正式环境所有 API 当前为「待审批」，正式环境返回 1004 属预期，审批通过后才能试算。
