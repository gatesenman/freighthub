# 货代询价助手 FreightHub 1.5.0 — 网页 / 服务器部署说明

同一套软件界面，可以放在内网电脑或云服务器上，大家用浏览器打开、登录后使用。**仍然只读：只查报价，不下单、不改平台资料、不重置密钥。**

## 1. 快速开始

| 方式 | 命令 |
|---|---|
| Windows | 双击 `start-server.bat`（改端口：`start-server.bat 8080`） |
| Linux / macOS | `./run-server.sh`（改端口：`./run-server.sh 8080`） |
| Docker | `docker build -t freighthub .`，然后<br>`docker run -d --name freighthub -p 8765:8765 -v fh-data:/data -e FREIGHT_HUB_ADMIN_PASSWORD='你的强密码' freighthub` |
| docker compose | 新建 `.env` 写 `FH_ADMIN_PASSWORD=你的强密码`，运行 `docker compose up -d` |

浏览器访问 `http://服务器IP:8765/`。默认监听 `0.0.0.0:8765`。需要 Python 3.10+（Docker 方式不需要）。

命令行参数（等价于环境变量）：`python run.py --server --host 0.0.0.0 --port 8765 --cert 证书.pem --key 私钥.pem --trust-proxy`

## 2. 第一次登录

- 首次启动自动创建管理员 `admin`。密码取自环境变量 `FREIGHT_HUB_ADMIN_PASSWORD`；没设置就随机生成，保存在 `data/INITIAL_ADMIN_PASSWORD.txt`（权限 600，日志里不打印密码）。
- 登录后：**工具 → 修改我的密码**（先改掉初始密码，再删除那个文件）；**工具 → 用户管理** 添加同事账号。

## 3. 角色权限

| 能力 | 管理员 admin | 普通用户 user |
|---|:--:|:--:|
| 询价、查看结果、导出 CSV | ✅ | ✅ |
| 查询历史 | 看全部 | 只看自己的 |
| 平台账号配置、批量导入 / 导出账号、测试连接 | ✅ | ❌ |
| 用户管理 | ✅ | ❌ |
| 修改自己的密码 | ✅ | ✅ |

平台的账号密码 / 密钥只保存在服务器 `data/config.json`（权限 600），**永远不会发到浏览器**；接口默认仅管理员可用，只有明确列出的查询类接口对普通用户开放。

## 4. 安全措施与建议

- 登录用 HttpOnly + SameSite=Lax Cookie；所有写操作校验 CSRF 令牌与 Origin；会话 8 小时无操作过期（`FREIGHT_HUB_SESSION_HOURS` 可改）；改密码 / 停用 / 删除用户会使其会话立即失效。
- 密码 PBKDF2-SHA256（24 万次迭代 + 随机盐）存于 `data/users.json`；同一 IP+用户名连续输错 5 次锁 5 分钟。
- **跨公网务必用 HTTPS**，否则密码在网上是明文。两种做法：
  1. 直接带证书：`--cert fullchain.pem --key privkey.pem`（或 `FREIGHT_HUB_CERT` / `FREIGHT_HUB_KEY`），自动给 Cookie 加 Secure。
  2. 放在 Nginx / Caddy 后面（推荐），软件只听本机：`FREIGHT_HUB_HOST=127.0.0.1`，并设 `FREIGHT_HUB_TRUST_PROXY=1`；代理需传 `Host`、`X-Forwarded-For`、`X-Forwarded-Proto`。Nginx 示例：
     ```
     location / { proxy_pass http://127.0.0.1:8765; proxy_set_header Host $host;
       proxy_set_header X-Forwarded-For $remote_addr; proxy_set_header X-Forwarded-Proto $scheme; proxy_read_timeout 300s; }
     ```
- 防火墙只放行需要的来源；云服务器安全组限制 8765（或 443）的来源 IP。
- 备份 `data/` 目录即备份全部配置（账号、用户、历史）。不要把 `data/` 提交到代码库或打进镜像。
- 登录失败不会重试：平台登录只试一次，失败就停并显示原因，避免触发平台风控锁号（与桌面版一致）。

## 5. 和桌面版的区别

- 没有窗口标题栏按钮；菜单里「退出」变为「退出登录」；右上角显示当前用户。
- 导入账号：弹出浏览器文件选择框上传 Excel / CSV；导出 CSV / Excel：由浏览器下载。
- 云途「登录模式」需要服务器上有 Chrome / Edge / Chromium（无界面服务器请装 chromium，或 Docker 构建加 `--build-arg WITH_CHROMIUM=1`）；若云途要求验证码，服务器上没人能点，建议改用云途 API 授权。其余平台（OIS 雨桐 / 环洋 / 中航、燕文、顺丰、欣航）不需要浏览器。
- 桌面版（安装包）行为不变，不需要登录。

## 6. 环境变量速查

| 变量 | 含义 | 默认 |
|---|---|---|
| `FREIGHT_HUB_MODE` | `server` = 网页模式 | 桌面模式 |
| `FREIGHT_HUB_HOST` / `FREIGHT_HUB_PORT` | 监听地址 / 端口 | `0.0.0.0` / `8765` |
| `FREIGHT_HUB_DATA` | 数据目录 | 程序目录下 `data/`（Docker：`/data`） |
| `FREIGHT_HUB_CERT` / `FREIGHT_HUB_KEY` | HTTPS 证书 / 私钥 | 无（HTTP） |
| `FREIGHT_HUB_TRUST_PROXY` | 在反向代理之后 | 关 |
| `FREIGHT_HUB_ALLOWED_ORIGINS` | 额外允许的 Origin（逗号分隔，如 `https://quote.example.com`） | 空 |
| `FREIGHT_HUB_ADMIN_PASSWORD` | 首个管理员密码（仅首次创建时使用） | 随机 |
| `FREIGHT_HUB_SESSION_HOURS` | 会话空闲过期小时数 | `8` |
