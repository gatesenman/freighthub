# FreightHub 网页版（Vercel）部署说明

线上地址：https://freight.gaosichun.dev　（Vercel Hobby 免费档 + Neon Postgres 免费档，区域 sin1）

## 自定义域名
- 已绑定 Vercel 项目 `freight-hub-web`：`https://freight.gaosichun.dev`（根路径 302 → `/login`）。DNS 在域名商处按 Vercel 的提示添加 CNAME/A 记录，Vercel 自动签发 HTTPS 证书。
- Origin / CSRF 校验按请求的 Host（Vercel 上自动信任 X-Forwarded-Host）比对，绑定新域名**不需要**改 `FREIGHT_HUB_ALLOWED_ORIGINS`；只有从别的站点（不同域名）发起写请求时才要把那个域名加进该变量（逗号分隔）。
- 换域名后验证：`python scripts/live_verify.py https://freight.gaosichun.dev`，或登录 → 查询一次 → 退出。
- Chrome 扩展 1.0.1 的默认网址已是该域名。

- `app/`：FastAPI 应用（与桌面版同一份代码，`FREIGHT_HUB_MODE=cloud` 时启用云端模式；在 Vercel 上自动启用）。
- 入口：`app/main.py`（Vercel FastAPI 预设直接识别），静态资源在 `public/static`（CDN），HTML 页面只经函数鉴权后返回。
- 数据库：Neon（免费档），全部状态都在库里（用户、角色、会话、审计、平台账号、平台登录会话、查询历史、导入批次）。
  Serverless 实例无状态、随时回收，所以不写本地文件。
- 加密：平台账号 / 登录会话 / 导入批次用 AES-256-GCM 加密后入库，密钥只在环境变量 `FH_DATA_KEY`（Vercel 敏感变量）。
- 权限：17 项权限 × 角色矩阵（管理 → 角色与权限），内置 管理员/主管/业务员/审计员/访客，可自建角色；改动立即生效。
- 审计：登录/失败登录/越权/用户与角色变更/账号修改·导入·导出/询价/历史查看·删除·导出…，记录 谁/做了什么/何时/IP，可筛选可导出 CSV，只增不删。
- 安全：HTTPS + HSTS、HttpOnly+Secure+SameSite Cookie、CSRF 头 + Origin 校验、登录限流（库内计数）、只读（无下单 / 无重置密钥 / 不改平台密码）。

## 仅桌面版可用
- 云途「登录账号」模式（需要真实浏览器 + 阿里云验证码）。网页版请改用云途「开放平台 API 授权」（需要 API 密钥）。
- 其他浏览器登录（CDP）类能力同理。中航使用纯 HTTP 登录，网页版可用。

## 运维
- 管理员口令：`ADMIN_PASSWORD.txt`（0600，不入库、不入仓库）。登录页默认勾选「30 天内保持登录」。
- 环境变量（Vercel 项目 production）：`DATABASE_URL`/`POSTGRES_URL`（Neon 集成自动注入）、`FH_DATA_KEY`、`FH_SETUP_CODE`。
  **丢失 `FH_DATA_KEY` = 已保存的平台账号无法解密**，需要用 `scripts/seed_cloud.py --overwrite` 重新导入。
- 本地备份密钥在 `.secrets/`（0700）。
- 重新部署：`vercel deploy --prod`（`.vercelignore` 已排除 .secrets / ADMIN_PASSWORD.txt / tests / data）。
- 线上验收：`python scripts/live_verify.py https://freight.gaosichun.dev`（Playwright，读 ADMIN_PASSWORD.txt）。
- 审计日志不自动清理（Neon 免费档 0.5 GB）；查询历史每用户保留最近 300 条。
